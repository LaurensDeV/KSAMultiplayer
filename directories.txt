# Directories of KSA Multiplayer servers, read by the mod every time it refreshes its list and by an
# advertising server once an hour. One URL to a line; a line starting with # is ignored, and a line
# that is not https:// is skipped silently.
#
# This file is here rather than in a build because a list compiled into one cannot be fixed without
# shipping another. Retiring a directory is a commented-out line here and adding one is a pull
# request, and neither is a release.
#
# A server reads this only while advertise is on. One nobody opted in fetches nothing and asks
# nobody, because a tarball that called home by default would be choosing for whoever downloaded it;
# and a server naming its own `directories` announces to those and never reads this file.
#
# A directory answers GET <url> with a listing, and takes announcements at /announce in place of a
# trailing /servers. docs/DIRECTORY.md is the whole specification; it is short on purpose, so that
# standing one up is an afternoon rather than a project.
